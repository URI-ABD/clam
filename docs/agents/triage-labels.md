# Triage Label Vocabulary

The following five canonical labels are used across this repository for classifying work items:

*   \`needs-triage\`: Requires initial review or assignment.
*   \`needs-info\`: Needs more context or information from a specific party.
*   \`ready-for-agent\`: Ready for an AI/Agent to process or action.
*   \`ready-for-human\`: Ready for human expert review and sign-off.
*   \`wontfix\`: Explicitly decided not to implement or address.
