# Issue Tracker Configuration (Local Markdown)

This repository uses local markdown files under \`.scratch/\` as its issue tracker.

Issues should be structured following this pattern:
\`<type>-<short-description>\`
Example: \`.scratch/feat-login-button/\`

When creating a new issue, please ensure it has the appropriate frontmatter tags and detailed markdown content.

This approach is suitable for solo development or teams preferring to keep all artifacts within this repository's history. The \`to-tickets\`, \`triage\`, and other related skills will monitor the \`.scratch/\` directory.
