\## Agent skills

### Issue tracker

Issues are tracked locally using markdown files within the `.scratch/` directory (Local Markdown approach). See `docs/agents/issue-tracker.md`.

### Triage labels

The standard canonical label vocabulary is used for triage: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

The domain documentation uses a multi-context layout, requiring domain-specific glossaries within component directories. See `docs/agents/domain.md`.
